This week, I focused on strengthening my data analysis skills by working with NumPy, Pandas, and SQL. The exercises helped me understand how these tools work together to manipulate data, explore datasets, and answer practical questions.

## What I Learned

With NumPy, I practised working with arrays, checking for missing values, identifying complex and real numbers, comparing values, testing approximate equality, and calculating memory usage. These exercises helped me understand how NumPy makes numerical operations more efficient.

With Pandas, I worked with Series and DataFrames. I practised converting data between different structures, performing arithmetic operations, handling numeric values, selecting columns, filtering rows, sorting data, and combining information. I also learned how important it is to use the correct column names and data types when working with datasets.

The SQL exercises introduced me to practical database operations, including inspecting database schemas, handling NULL values, grouping records, joining tables, combining query results, ranking data with window functions, and calculating running totals.

## Applying My Knowledge to Real Data

One of the key parts of this week's work involved analysing weather data for six cities in 2014. The analysis focused on measures such as average mean temperature, highest maximum temperature, lowest minimum temperature, and total precipitation.

Other exercises involved customer churn, tuberculosis and population data, international trade exports, and loan approvals. These tasks showed me how Python and SQL can be used to investigate different types of data and answer specific analytical questions.

## Challenges and Lessons Learned

One important lesson was the need to work with the actual dataset specified in an assignment rather than relying on sample or invented data. Meaningful analysis depends on using the correct source, understanding its structure, and verifying the results.

I also learned to pay closer attention to NULL values, integer and decimal calculations, inconsistent country names, column names containing spaces, and the ordering of results produced by SQL window functions.

These details may appear small, but they can affect the accuracy of an analysis. I am learning that writing a query is only one part of the process; checking whether the result answers the question correctly is equally important.

## What I Will Improve Next

Going forward, I want to become more systematic in my approach to data analysis. I will begin by inspecting datasets and their schemas, test queries in smaller steps, check data quality, and verify results before drawing conclusions.

I also want to improve how I communicate analytical findings so that my work is not only technically correct but also clear and useful to others.

## Final Reflection

Week 6 reminded me that data analysis involves more than writing code. It requires curiosity, attention to detail, critical thinking, and the ability to distinguish verified findings from assumptions.

As I continue my learning journey, I look forward to applying NumPy, Pandas, and SQL to real-world problems and developing the confidence to turn raw data into meaningful insights.
